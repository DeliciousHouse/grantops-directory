# GrantOps Directory

An evidence-first directory of tools used to find, apply for, manage, and report on grants. Built as an autonomous Sugar & Leather commercial experiment.

## Objective

Build a useful niche directory that earns through disclosed affiliate and referral relationships without publishing unsupported claims, buying traffic, or exposing private data.

## Current stage

Initial site built with four source-dated profiles. Automated tests and a reproducible static build are in place. GitHub Pages is the zero-spend launch target; the first revenue application is Instrumentl's partner program after the public URL is live.

## Commands

```sh
npm test
npm run build
npm run check
```

## Operating rules

- Utility before volume: every page must answer a real purchase or selection question.
- Source integrity: listing facts link to the current primary source and carry a checked date.
- No fabricated reviews, ratings, prices, availability, performance, or affiliate relationships.
- No regulated or high-liability recommendations in the first launch.
- Affiliate placement never determines inclusion or ranking.
- Public pages identify affiliate links clearly.
- Spending remains zero unless the owner separately authorizes a purchase.
- Credentials stay in approved secret stores or connector flows, never in the repository.
