# AGENTS.md

This repository is a commercial directory experiment. Treat every public claim as evidence-bearing.

- Never invent listings, ratings, testimonials, prices, availability, performance, traffic, partner status, or revenue.
- Record a primary source URL and `checked_at` date for each material listing fact.
- Label assumptions and recommendations separately from verified facts.
- Do not publish secret-bearing files, raw credentials, private messages, or customer/client data.
- Affiliate links require clear disclosure; compensation never controls inclusion or ranking.
- No spending, contractual acceptance, payment movement, legal/tax attestation, account-permission change, or destructive action without owner authorization for that specific event.
- Builds, tests, link checks, and structured-data validation must pass before a public release.
- Keep a changelog of material content, monetization, and automation changes.
